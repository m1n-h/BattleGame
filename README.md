# ⚔️ 자바 객체지향 콘솔 RPG 배틀 시뮬레이터

《Head First Java》 2장을 공부하며 이론으로 배운 객체지향 프로그래밍(OOP) 개념을 직접 응용해 만든 콘솔 기반 미니 배틀 시뮬레이터입니다.

---

## 📌 프로젝트 개요
- **학습 목적:** 자바의 핵심인 **객체(Object)와 클래스(Class)**의 관계 이해 및 객체 간 상호작용 구현
- **개발 환경:** Java 21 / IntelliJ IDEA / Git

---

## 🗺️ 클래스 구조

자바의 객체지향 원칙인 '역할의 분리'를 위해 총 3개의 클래스로 나누어 설계했습니다.

1. **`Hero.java`** : 용사 캐릭터의 상태(`hp`, `attackPower`)와 행동(`attack`, `takeDamage`)을 정의
2. **`Slime.java`** : 몬스터 캐릭터의 상태와 행동을 정의
3. **`BattleGame.java`** : `main` 메서드가 있는 실행 클래스. 힙(Heap) 메모리에 두 객체를 띄우고(`new`), 한쪽의 HP가 0이 될 때까지 무한 배틀(`while`)을 진행시키는 무대 감독 역할

---

## 💡 이번 장을 통해 배운 점

- **설계도와 실제 객체:** 클래스는 설계도일 뿐이며, `new` 키워드로 실제 객체를 생성해야 메모리에 상태와 행동이 살아 숨 쉰다는 것을 체감했습니다.
- **객체의 협력 (메시지 전달):** `hero.attack(slime);`처럼 하나의 객체가 다른 객체의 메서드를 호출하며 상호작용하는 흐름을 통해 객체지향적인 코드 작성법을 이해했습니다.

---

## 🛠️ 개발 중 직면한 문제와 해결
- **문제점:** Chapter 2 수준에서는 반복문이 없어 캐릭터들이 죽을 때까지의 교전을 수동으로 복사 붙여넣기 해야 하는 비효율 발생
- **해결책:** 책의 다음 진도를 참고하여 **`while` 반복문**과 **`if` 조건문**을 선행 학습 후 도입. 두 캐릭터 중 한 명의 HP가 0 이하가 될 때까지 자동으로 실시간 배틀이 진행되도록 로직을 업그레이드 완료

## 🚀 앞으로의 업데이트 계획
- 책을 더 읽어가며 **상속(Inheritance)**과 **다형성(Polymorphism)**을 적용해 다양한 캐릭터를 확장할 예정입니다.
